# Spike Court 2.5D

Game voli mobile 2.5D bertema Haikyuu!! (fan project / prototipe).
Lapangan dan fisika bola di ruang 3D, karakter berupa sprite 2D billboard.

## Isi repo
- `ARCHITECTURE.md` : rekomendasi engine, arsitektur skrip, alur game, setup scene
- `Assets/Scripts/` : skrip C# Unity (BallPhysics, PlayerController, SetterAI, BurstMeter, dll)
- `WebPrototype/spike-court.html` : prototipe 3D yang bisa langsung dibuka di browser (Three.js)

## Cara pakai skrip di Unity
1. Buat project Unity baru (3D URP, versi 2022.3 LTS atau Unity 6).
2. Salin folder `Assets/Scripts` dari repo ini ke `Assets/` project kamu.
3. Ikuti bagian "Setup scene" di `ARCHITECTURE.md`.
